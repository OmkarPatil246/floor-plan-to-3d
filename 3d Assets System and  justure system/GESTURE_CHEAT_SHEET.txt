┌──────────────────────────────────────────────────────────────────────────────┐
│ BASIC GESTURES                                                               │
└──────────────────────────────────────────────────────────────────────────────┘

🖐️  OPEN HAND (All 5 fingers spread)
    ├─ Action: Move cursor around
    ├─ Use: Navigate, hover over objects
    └─ Cursor: Cyan ring follows index fingertip

👆 POINT (Only index finger up)
    ├─ Action: Precise cursor control
    ├─ Use: Aim at small objects, fine control
    └─ Cursor: Yellow ring, more stable

🤏 PINCH (Thumb + index tips touch)
    ├─ Action: SELECT & GRAB
    ├─ Priority 1: Grab placed furniture ⭐ NEW!
    ├─ Priority 2: Select from hotbar
    ├─ Priority 3: Pull corner handle to resize
    └─ Cursor: Green ring when pinching

✌️  PEACE SIGN (Index + middle up)
    ├─ Action: DELETE selected furniture
    ├─ Hold: 0.7 seconds
    └─ Visual: Orange progress arc fills

🖖 THREE FINGERS (Index + middle + ring)
    ├─ Action: DUPLICATE selected furniture
    ├─ Hold: 0.7 seconds
    └─ Visual: Orange progress arc fills

✊ FIST (All fingers closed)
    ├─ Action: CANCEL / Deselect
    ├─ Cooldown: 500ms
    └─ Toast: "FIST - CANCEL!"

┌──────────────────────────────────────────────────────────────────────────────┐
│ ADVANCED GESTURES                                                            │

🤏 + 🤏 TWO-HAND PINCH (Both hands pinching)

    ├─ Bring together: Scale DOWN ⬇️
    ├─ Twist hands: Rotate object 🔄
    └─ Visual: Purple line connects hands

┌──────────────────────────────────────────────────────────────────────────────┐
│ RESIZE FURNITURE                                                             │
└──────────────────────────────────────────────────────────────────────────────┘

Step 1: Select furniture (pinch it)
        🪑 → Blue box + 8 corner handles appear
        
Step 2: Point at corner handle (turns yellow)
        [○] ← Yellow when hovered
        
Step 3: PINCH the handle
        🤏
        
Step 4: Pull away = Scale UP, Pull in = Scale DOWN
        🔧 Pull ↔️
        
Step 5: Release to confirm
        🖐️

Range: 0.2x to 5.0x (in 0.05 steps)

┌──────────────────────────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

❌ Can't select furniture?
    ✅ Walk closer (WASD keys)
    ✅ Switch to Orbit View (V key)
    ✅ Point directly at furniture
    ✅ Check within 12m reach

❌ Hotbar keeps selecting?
    ✅ Move hand away from left edge
    ✅ 3D objects now have priority!
    ✅ Cursor must be INSIDE slot to select

❌ Gesture not detected?
    ✅ Good lighting required
    ✅ Keep hand in camera frame
    ✅ Palm facing camera
    ✅ Fingers clearly separated

❌ Camera not working?
    ✅ Click camera icon in address bar
    ✅ Allow webcam permission
    ✅ Click retry button in UI

❌ Object won't move?
    ✅ Check within 12m reach
    ✅ Keep pinch held while dragging
    ✅ Make sure not over dustbin
